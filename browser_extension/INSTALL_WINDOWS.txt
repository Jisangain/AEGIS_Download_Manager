Aegis Browser Extension for Windows

Requirements:
- Aegis Download Manager for Windows
- Chrome, Brave, or Microsoft Edge
- No Python installation is required

Setup:
1. Extract this ZIP to a permanent folder. Keep it there after setup.
2. Open chrome://extensions, brave://extensions, or edge://extensions.
3. Enable Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
4. Run install_host.bat. It detects the loaded extension automatically; you do not need to copy or enter its ID.
5. Restart the browser and launch Aegis Download Manager.

The extension must be loaded from the same extracted folder that contains install_host.bat. If setup says it cannot find the extension, check that folder selection and run install_host.bat again.

The native host executable is included in this ZIP. Do not use the repository's
Code > Download ZIP archive for Windows native messaging; source archives do not
include the packaged native host executable.
