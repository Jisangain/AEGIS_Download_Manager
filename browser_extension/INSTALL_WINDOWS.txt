Aegis Browser Extension for Windows

Requirements:
- Aegis Download Manager for Windows
- Chrome, Brave, or Microsoft Edge
- No Python installation is required

Setup:
1. Extract this ZIP to a permanent folder. Keep it there after setup.
2. Run install_host.bat. It opens a browser extensions page and waits for setup.
3. In that browser, enable Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json. The installer detects the extension ID and registers the native host automatically; do not close its window.
4. When the installer says setup is complete, restart the browser and launch Aegis Download Manager.
5. Click the Aegis toolbar icon. It checks the connection automatically and displays Connected if the native host is reachable.

The extension must be loaded from the same extracted folder that contains install_host.bat. The browser requires Developer mode and the Load unpacked action for an unpacked extension. No extension ID copying or second installer run is needed.

The recommended download is the Aegis Browser Extension ZIP release asset. If you
use GitHub Code > Download ZIP, install_host.bat downloads the native host from
the latest GitHub release. This fallback requires internet access; Python is not
required.
